COMMON ISSUES & SOLUTIONS
══════════════════════════════════════════════════════════════════════════════

Issue: "Password verification required"
Solution: You must login as Admin and enter password

Issue: "Incorrect password"
Solution: Use manager password (not admin password)

Issue: "Reason must be at least 10 characters"
Solution: Enter longer reason (e.g., "Corrected the error")

Issue: No pending transactions showing
Solution: Check database for 'Pending' status transactions

Issue: No completed transactions showing
Solution: Check database for 'Completed' and is_locked = 1
