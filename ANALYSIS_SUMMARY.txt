KEY INSIGHTS
══════════════════════════════════════════════════════════════════════════════

1. joborder.php is SPECIAL - it auto-creates demo staff & mechanics
   Use this feature to save time on manual data generation

2. reconciliation.php has BUILT-IN sample data generation
   It generates realistic fuel reconciliation if no real data exists

3. dashboard.php uses fallback VALUES (not fallback data)
   It shows random numbers instead of actual data when tables missing
   This is why dashboard works but shows incorrect metrics

4. product_types is THE CRITICAL MISSING TABLE
   It's referenced in queries for fuel vs merch categorization
   Must exist before any product/inventory generation

5. sale_items is THE SECOND CRITICAL TABLE
   Reports.php JOINs to this table but it may not exist
   Without it, report generation fails on complex JOINs

6. ALL pages have graceful error handling
   No crashes - they just return empty results when tables missing
   This makes it hard to know what's missing without close inspection
